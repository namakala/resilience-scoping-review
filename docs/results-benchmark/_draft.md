# Benchmark Evaluation Results

This benchmark compared the pipeline output against two human coders across a set of 86 overlapping exemplars. At level 1, the machine coder matched neither human on code name assignments (Jaccard index = 0.0, Krippendorff's alpha = 0.0). Coding agreement among coders were low, even the two human coders agreed weakly on their code name assignments, producing an alpha of 0.112. At level 2, the Hungarian matching algorithm found that every machine code maps to a human code. The Hungarian mean similarity between machine and human coders was 0.44 (95% CI = 0.41-0.54). This value is 83% of the human-human baseline, which was 0.54 (95% CI = 0.49-0.57). The two coding schemes divide the evidence in compatible ways even when they do not use the same words. At level 3, LLM-assisted interpretation narratives scored 0.636 in semantic similarity against the exemplar contents they summarized. The interpretation-theme semantic similarity was low (0.168) because the themes came from largely disjoint exemplar sets. Interpretations deliberately span multiple ontology branches, and themes from different branches share less overlapping evidence. Machine and human coders converge on the conceptual organization of the evidence even though they use different terminology. The gap between coders concerns their naming conventions more than differences in underlying analytical structure.
