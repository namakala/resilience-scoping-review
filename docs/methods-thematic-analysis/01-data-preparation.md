# Data Preparation and Ontology Design

A hierarchical tag ontology was developed to organise the qualitative evidence extracted from the scoping review literature. The ontology comprised 31 tags organised under four top-level categories: Problem, Resilience, Resolution, and TheoreticalModel. Tags were structured as a directed acyclic graph (DAG) with parent-child relationships defining the semantic hierarchy (e.g., Problem.Impact.Mediation as a child of Problem.Impact). Each tag was accompanied by a textual description and a count of constituent exemplars to facilitate scoping of the analysis.

Exemplar data were prepared as a structured CSV file containing four columns: a unique numeric identifier, the source document filename, the assigned ontology tag, and the extracted textual content. Each row represented a single evidence excerpt from a reviewed article, linked to exactly one tag within the ontology. The tag assignment governed all downstream analysis by restricting semantic retrieval, code inference, and theme aggregation to the relevant ontology subtree. This design ensured that analytical outputs remained grounded in the hierarchical structure of the research domain.

Two categories of immutable artifacts were established as the canonical evidence base: tags and exemplars were fixed at ingestion and never regenerated without explicit manual invalidation. All data were converted from CSV to Parquet format using the Polars library [@vink2022polars] with lazy evaluation to minimise memory footprint. A content hash (SHA-256) was computed for each exemplar row to enable change detection and prevent accidental re-ingestion of unchanged data.

The Parquet-based storage strategy provided columnar compression and efficient predicate pushdown for subsequent retrieval operations. The persistence layer validated schema compliance, checked referential integrity of parent-tag references, and enforced the absence of duplicate identifiers before committing the data. Once written, these immutable artifacts served as the stable semantic foundation for all downstream embedding, indexing, and inference stages.
